# Piu Piu Pop

Быстрая браузерная игра «три в ряд» в космическом сеттинге. Работает без сборки и зависимостей — достаточно открыть `index.html`.

## Возможности

- поле 8×8 без готовых совпадений на старте;
- управление кликом, тапом и свайпом;
- каскады и множитель комбо;
- ракеты за четыре ядра, бомбы за пересечения и нова за пять;
- автоматическая проверка доступных ходов;
- подсказка и перемешивание;
- сохранение рекорда в браузере;
- адаптивный интерфейс для телефона и компьютера.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте <http://localhost:8080>.
