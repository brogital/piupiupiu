# Осколки Бури

Тактическая браузерная match-3 RPG в оригинальном мире расколотых островов.

## Вертикальный срез

- черепа наносят прямой урон Пожирателю маяков;
- красный, голубой и фиолетовый резонансы заряжают способности трёх героев;
- зелёные нити лечат, жёлтые дают осколки знания;
- босс отвечает после каждого обычного хода и распространяет порчу;
- комбинация из четырёх и более знаков даёт дополнительный ход.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте <http://localhost:8080>.
