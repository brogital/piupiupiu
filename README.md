# Осколки Бури

Тактическая браузерная match-3 RPG в оригинальном мире расколотых островов.

## Игровой цикл

- пять последовательно открывающихся боевых узлов;
- постоянные награды и прокачка Рейнара, Элли и Сайры;
- разные параметры, модификаторы и темп противников;
- сохранение кампании и рангов героев в браузере;
- стихийное поле 8×8: огонь, вода, жизнь, свет, бездна и черепа;
- способности, щиты, лечение, порча, каскады и дополнительные ходы.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте <http://localhost:8080>.
